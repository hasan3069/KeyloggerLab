# KeyloggerLab – Cybersecurity Simulation

## Project Overview
KeyloggerLab is an educational cybersecurity project
demonstrating local input logging and Windows event
collection in a controlled laboratory environment.

## Features
- Local command logging
- Manual input simulation using Tkinter
- JSONL event storage
- Windows event collection
- SQLite database integration
- HTML-based lab dashboard

## Technologies Used
- Python
- Tkinter
- PowerShell
- SQLite
- HTML
- JSON

## Project Files
- app.py – Main application
- cmd_logger.py – Local command logger
- input_simulator.py – Manual input simulator
- database_setup.py – Database setup
- collect_events.ps1 – Windows event collection
- keystroke_lab.html – Lab interface

## Educational Purpose
This project demonstrates cybersecurity logging
concepts in an isolated environment.

It does not require or authorize monitoring
other people's keystrokes.

## Safety
Use only in an authorized laboratory environment.
Do not enter passwords or confidential information.
